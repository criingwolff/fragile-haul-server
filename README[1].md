# Fragile Haul server

Upload these three files to a new GitHub repository, then on render.com choose
New > Blueprint and pick the repository. When it says Live, open its address in a
browser: you should see "Fragile Haul server is running".

In the game, tap ONLINE SETUP and paste that address.

To run it on a computer instead: install Java 17 and run
    java -jar fragile-haul-server.jar
